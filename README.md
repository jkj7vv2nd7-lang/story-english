リーディング特化の英語学習アプリ。単一ファイル `index.html` だけで動作します（外部ファイル不要、学習記録は端末内に保存）。物語は書き下ろしオリジナル13話と、パブリックドメインの名作を新たに書き直した「名作コレクション」39話の、全52話（総約25,890語）です。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成（例：名前 `story-english`、Public）
2. リポジトリ画面で **Add file → Upload files** を選び、このフォルダの `index.html`（と任意で `README.md`）をアップロードして Commit
3. リポジトリの **Settings → Pages** を開く
4. **Build and deployment** の Source で **Deploy from a branch** を選び、Branch に **main / (root)** を指定して Save
5. 数分待つと、Pages の画面に公開URLが表示されます

公開URLの形式： `https://<ユーザー名>.github.io/story-english/`

スマホやタブレットでそのURLを開き、ブラウザの「ホーム画面に追加」をするとアプリのように起動できます。

## 使い方メモ

- 読み上げ・発音チェックはブラウザと端末の音声機能を使います。対応していない環境では、読む・解く・単語帳などの学習はそのまま使えます
- 録音機能はマイク許可が必要です（許可しない場合は他の機能に影響しません）
- 学習記録は各端末のブラウザ内に保存されます。端末を変えると引き継がれません
